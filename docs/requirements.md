# เอกสารข้อกำหนดและความต้องการของระบบ (Project Requirements Specification)

> **ชื่อระบบ:** ระบบบริหารจัดการสถานศึกษาและข้อมูลนักเรียนแบบครบวงจร (School & Student Management System - SMS)  
> **เอกสารเวอร์ชัน:** 1.0.0 (สรุปผลจากการสัมภาษณ์ Grill-me)  
> **สถานะ:** ข้อมูลครบถ้วนสมบูรณ์ พร้อมสำหรับการวางแผนสถาปัตยกรรมและการพัฒนา

---

## 1. วัตถุประสงค์และภาพรวมของระบบ (Project Overview & Objectives)

ระบบเว็บแอปพลิเคชันบริหารจัดการสถานศึกษาแบบครบวงจร (Full-Stack School & Student Management System) ได้รับการออกแบบขึ้นเพื่อจัดการกระบวนการทำงานหลักของโรงเรียน ตั้งแต่การจัดการข้อมูลประวัตินักเรียน, การเช็คชื่อเข้าเรียนประจำวัน, การบันทึกผลการเรียนและคำนวณเกรด, การจัดตารางสอน, การประกาศข่าวสาร ตลอดจนการสั่งงานและส่งการบ้านของนักเรียน

ระบบทำงานแบบ **Full-Stack ในตัวเดียว (All-in-One)** มีทั้ง Frontend UI ที่ตอบสนองลื่นไหล รองรับ Full-Responsive บนทุกอุปกรณ์ และ Backend API / Server Actions ที่เชื่อมต่อกับฐานข้อมูล SQLite จัดเก็บข้อมูลถาวร พร้อมชุดข้อมูลตั้งต้น (Seed Data) ภาษาไทยที่สมจริง

## 2. กลุ่มผู้ใช้งานและสิทธิ์การเข้าถึง (User Roles & Access Control)

ระบบแบ่งผู้ใช้งานออกเป็น 3 บทบาทหลัก โดยแต่ละบทบาทจะมีหน้า Dashboard และสิทธิ์การเข้าถึงเมนูที่แตกต่างกันอย่างชัดเจน:

| บทบาท (Role) | สิทธิ์และการเข้าถึง (Permissions & Responsibilities) |
| :--- | :--- |
| **Admin (ผู้ดูแลระบบ)** | - จัดการข้อมูลผู้ใช้งานทั้งหมด (เพิ่ม/ลบ/แก้ไข/รีเซ็ตรหัสผ่าน ครูและนักเรียน)<br>- จัดการข้อมูลชั้นเรียน, ห้องเรียน และรายวิชาหลักสูตร<br>- ดูภาพรวมสถิติทั้งโรงเรียน (จำนวนนักเรียน, อัตราการมาเรียนเฉลี่ย, สรุปผลการเรียน)<br>- สร้างและปักหมุดประกาศข่าวสารของโรงเรียน<br>- สำรองและส่งออกข้อมูล (Export CSV/PDF) |
| **Teacher (คุณครู/อาจารย์)** | - บันทึกและตรวจเช็คชื่อการเข้าเรียนประจำวันของนักเรียนในห้องที่ปรึกษา / รายวิชาที่สอน<br>- บันทึกคะแนนเก็บ คะแนนสอบกลางภาค/ปลายภาค และกดคำนวณเกรดอัตโนมัติ<br>- ดูตารางสอนประจำสัปดาห์ของตนเอง<br>- สร้างการบ้าน/งานที่มอบหมาย กำหนดกำหนดส่ง และตรวจให้คะแนนพร้อม Feedback |
| **Student (นักเรียน)** | - ดูประวัติข้อมูลส่วนตัวและผลการเรียน (GPA, ผลสอบแต่ละวิชา)<br>- ดูประวัติการเข้าเรียนของตนเอง (มาเรียน, สาย, ลา, ขาด)<br>- ดูตารางเรียนประจำสัปดาห์และห้องเรียน<br>- ดูรายการการบ้าน ส่งงาน แนบไฟล์ และดูคะแนนพร้อมคำติชมจากครูผู้สอน<br>- รับทราบประกาศข่าวสารและกิจกรรมของโรงเรียน |

## 3. รายการฟังก์ชันและโมดูลการทำงาน (Core Modules & Features)

### 3.1 ระบบยืนยันตัวตนและความปลอดภัย (Authentication & Authorization)
- ระบบเข้าสู่ระบบด้วย Email/Username และ Password
- เข้ารหัสผ่านด้วย **bcrypt** ปลอดภัยตามมาตรฐานความปลอดภัย
- จัดการ Session ผ่าน **HTTP-only Secure Cookie** เพื่อป้องกัน XSS
- มี **Middleware Route Protection** ป้องกันการเข้าถึงหน้าที่ไม่ได้รับอนุญาตตาม Role
- หน้าแสดงข้อผิดพลาด (Access Denied / 403) และหน้า 404 สวยงาม

### 3.2 ระบบจัดการข้อมูลประวัตินักเรียนและห้องเรียน (Student & Class Management)
- แสดงรายการนักเรียนในรูปแบบตารางข้อมูล (Data Table) พร้อม Pagination
- ระบบค้นหาอัจฉริยะ (Search by Name, Student Code, National ID)
- ตัวกรองตามระดับชั้น (ม.1 - ม.6) และห้องเรียน (ห้อง 1, ห้อง 2, ฯลฯ)
- ฟอร์มเพิ่ม/แก้ไขข้อมูลนักเรียน พร้อม Client & Server-side Validation
- หน้าโปรไฟล์นักเรียน (Student Profile Detail) แสดงข้อมูลส่วนตัว, ข้อมูลผู้ปกครอง, ประวัติการเรียน
- ปุ่มส่งออกข้อมูลเป็น CSV

### 3.3 ระบบเช็คชื่อเข้าเรียนและแดชบอร์ดสถิติ (Daily Attendance & Analytics)
- หน้าเช็คชื่อประจำวันแบบ Quick Checklist:
  - สถานะ: **มาเรียน (Present)**, **สาย (Late)**, **ขาดเรียน (Absent)**, **ลาป่วย/ลากิจ (Leave)**
  - มีปุ่ม "มาเรียนทั้งหมด" เพื่อความสะดวกรวดเร็วในการเช็คชื่อ
- สรุปสถิติประจำวันและรายเดือนในรูปแบบกราฟ (Attendance Rate % Chart)
- แจ้งเตือนนักเรียนที่ขาดเรียนเกินเกณฑ์ที่กำหนด

### 3.4 ระบบบันทึกคะแนนและคำนวณเกรดอัตโนมัติ (Gradebook & Academic Evaluation)
- บันทึกคะแนนแยกตามสัดส่วน: คะแนนเก็บ (Homework/Quiz), กลางภาค (Midterm), ปลายภาค (Final)
- ระบบคำนวณเกรดอัตโนมัติตามมาตรฐานกระทรวงศึกษาธิการไทย:
  - 80–100: เกรด 4.0
  - 75–79: เกรด 3.5
  - 70–74: เกรด 3.0
  - 65–69: เกรด 2.5
  - 60–64: เกรด 2.0
  - 55–59: เกรด 1.5
  - 50–54: เกรด 1.0
  - 0–49: เกรด 0
- หน้าพิมพ์/แสดงผลใบรายงานผลการเรียน (Transcript / Grade Report View)

### 3.5 ระบบตารางเรียนและตารางสอน (Timetable & Weekly Schedule)
- แสดงตารางเรียนในมุมมองปฏิทินสัปดาห์ (วันจันทร์ - วันศุกร์)
- แยกตารางเรียนตามห้องเรียน (สำหรับนักเรียน) และตารางสอนตามครูผู้สอน (สำหรับครู)
- แสดงข้อมูลรหัสวิชา, ชื่อวิชา, ครูผู้สอน, ห้องเรียน, และช่วงเวลาเรียน

### 3.6 ระบบประกาศข่าวสารและกิจกรรม (Announcements & Bulletin Board)
- แสดงประกาศข่าวสารพร้อม Tag หมวดหมู่ (เช่น กิจกรรม, วิชาการ, ด่วนที่สุด)
- รองรับการปักหมุดข่าวสำคัญ (Pinned Announcements)
- กำหนดสิทธิ์การมองเห็น (เห็นทุกคน, เฉพาะครู, เฉพาะนักเรียน)

### 3.7 ระบบการบ้านและการส่งงาน (Assignments & Submissions)
- ครูสามารถสร้างการบ้านใหม่ ระบุหัวข้อ คำอธิบาย กำหนดส่ง และคะแนนเต็ม
- นักเรียนสามารถดูรายการงานที่ต้องส่ง สถานะ (รอส่ง / ส่งแล้ว / ตรวจแล้ว)
- นักเรียนส่งงานพร้อมกรอกคำอธิบายหรือแนบลิงก์ไฟล์
- ครูตรวจสอบงาน กรอกคะแนน และเขียนข้อเสนอแนะ (Feedback)

## 4. สถาปัตยกรรมทางเทคนิค (Technical Stack)

| ส่วนประกอบ (Component) | เทคโนโลยีที่เลือกใช้ (Selected Technology) | เหตุผลและความเหมาะสม |
| :--- | :--- | :--- |
| **Framework** | **Next.js (App Router)** | ทรงพลัง มีทั้ง React Server Components (RSC), Server Actions, API Routes และ Client Components ในโปรเจกต์เดียว |
| **Language** | **TypeScript (Strict Mode)** | ป้องกันข้อผิดพลาดของข้อมูล Type Safety ครบวงจรตั้งแต่ Database จนถึง UI |
| **Styling** | **Tailwind CSS** | พัฒนา Responsive ได้รวดเร็ว แม่นยำ และมี Utility classes ครอบคลุม |
| **Icons & Components** | **Lucide React + Radix UI Primitives** | ไอคอนทันสมัย สวยงาม และ Component พื้นฐานที่รองรับ Accessibility มาตรฐาน WAI-ARIA |
| **Database** | **SQLite (ผ่าน `better-sqlite3` หรือ `@libsql/client`)** | เป็น Serverless Database ในเครื่อง รันได้ทันทีโดยไม่ต้องลง Docker หรือเซิร์ฟเวอร์ฐานข้อมูลแยก |
| **ORM** | **Drizzle ORM** | Type-safe ORM ประสิทธิภาพสูง โค้ดกระชับ ไม่ซับซ้อน และทำ Schema Migrations ได้ง่าย |
| **Validation** | **Zod** | ตรวจสอบ Schema ข้อมูลทั้งตอนรับ Request และตรวจสอบฟอร์ม |
| **Theme System** | **next-themes** | สลับ Light Mode / Dark Mode ได้อย่างราบรื่น ไม่มีปัญหา Hydration Mismatch |

## 5. การออกแบบ UI/UX และการรองรับ Full-Responsive

### โทนสีและสไตล์ (Design System)
- **สไตล์:** Modern Clean & Educational
- **Primary Color:** Deep Indigo / Slate Blue (`#1e40af`, `#3b82f6`) สื่อถึงความน่าเชื่อถือ มั่นคง และการศึกษา
- **Secondary / Accent:** Emerald Green (สำหรับสถานะผ่าน/มาเรียน), Amber (สำหรับสาย/รอดำเนินการ), Rose Red (สำหรับขาดเรียน/แจ้งเตือน)
- **Backgrounds:** Slate-50 / White สำหรับ Light Mode และ Zinc-900 / Slate-950 สำหรับ Dark Mode

### Layout Breakpoints & อุปกรณ์ที่รองรับ
1. **Mobile (320px – 480px):**
   - การนำทาง: Hamburger Drawer หรือ Bottom Navigation Bar เข้าถึงฟังก์ชันหลักได้ด้วยนิ้วโป้ง
   - ตารางข้อมูล: ปรับเป็นการ์ด (Responsive Card View) เพื่อให้อ่านง่าย ไม่ต้องเลื่อนแนวนอน
   - Touch Target: ปุ่มและลิงก์มีขนาดอย่างน้อย `44x44px`
2. **Tablet (768px – 1024px):**
   - การนำทาง: Sidebar แบบย่อ (Icon Sidebar) หรือ Collapsible Drawer
   - การจัดวาง: Grid 2 คอลัมน์สำหรับ Dashboard Widgets
3. **Desktop (1280px – 1920px+):**
   - การนำทาง: Full Sidebar พร้อมตราสัญลักษณ์โรงเรียนและข้อมูลโปรไฟล์ผู้ใช้
   - การจัดวาง: Grid 3-4 คอลัมน์, Data Table เต็มรูปแบบพร้อม Sorting, Filtering, และ Actions

## 6. ข้อกำหนดการทดสอบด้วย Chrome DevTools MCP

ทุกหน้าจอและฟังก์ชันจะต้องผ่านการตรวจสอบตามเกณฑ์ดังต่อไปนี้:
1. **Viewport Verification:** ทดสอบเรนเดอร์ใน 3 ขนาดหน้าจอหลัก (Mobile 390px, Tablet 768px, Desktop 1440px)
2. **Visual Consistency:** จับภาพ Screenshot เพื่อตรวจเช็คความเรียบร้อยของ UI
3. **Zero Errors:** ไม่มี Uncaught Exceptions, Console Errors, หรือ 404/500 API Calls
4. **Lighthouse Audit:** ค่าคะแนน Performance, Accessibility, Best Practices ต้องผ่านเกณฑ์มาตรฐาน (≥ 90)
